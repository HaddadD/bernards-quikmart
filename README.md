# Bernard's Quik Mart & Laundromat

Landing page for Bernard's Quik Mart & Laundromat, 126 Bayview Dr, Summerside, PEI.

**Live site:** https://haddadd.github.io/bernards-quikmart/

A single static page (`index.html`) with photos in `images/`. No build step. Open it directly, or serve the folder:

```bash
python3 -m http.server 8660
```

## Before going live

- The photos are customer uploads from the Google Maps listing. Get the owner's OK or replace them with their own.
- The Google reviews are static copies. Refresh them, or wire up the Places API for live reviews.
- Confirm the weekday closing time: Google says 10 p.m., but the door sign appears to say 9 p.m.
